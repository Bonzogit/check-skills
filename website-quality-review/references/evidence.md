# 证据与已知经验

来源是用户已确认的真实项目故障模式及当前建站协议，经过通用化整理；不携带私人网址、账号或项目数据。这些经验用来选检查，不能充当当前项目通过证据。

- 样式无变化：先核对当前 DOM、优先级与 computed style，避免猜选择器后叠加全局 important。
- 图片圆角仍露方底：核对最外裁切框及内层换图/运动。
- 点击不稳定：图片内部可以运动，链接和按钮命中区保持稳定；菜单关闭后核对阅读位置。
- 吸附或定位偏移：包括收缩页眉、减少动态布局、反向进入和末尾释放。
- 图片慢导致空白：保留当前可见图，处理错误与恢复，检查首屏请求而非预取全部隐藏图。
- 动效看起来通过：源码、库载入、虚拟 DOM 或截图采集都不足以证明真实播放；查看起止与中间状态并操作。
- 邮件或翻译“成功”：区分入库、供应商接受、送达/实收，以及译文生成、缓存复用、页面呈现与语义。

每项 pass 的证据包含当前版本、时间、页面、环境和操作结果；截图与日志按用途组合。工具失败保留 unverified，不能继承已失效截图。记录工具及版本、实际调用、输出、失败与替代；只写真实执行者，无独立评审则明确。

截图前检查页面是否为错误页、图片是否解码、内容是否仍在加载或淡入。HTTP请求或截图调用成功不能证明参考画面有效。主题或服务端代码修改后确认新进程/版本再测；热缓存的旧主题不能作为新版本结果。

公开交付移除凭据、个人信息、私有附件、客户询盘与本机绝对路径。项目私有报告可以记录实际环境，发布 Skill 时只保留脱敏的方法、合成测试与覆盖说明。
