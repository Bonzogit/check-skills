# 实际画面对照

先确认当前版本、入口、视口、语言与相关状态，以及图片/字体是否可用。对照目标可以是明确设计规格、已锁定参考、原站保留项或用户提供画面。比较相关部分，不要求复制其他品牌内容；当前访客任务优先。

依次判断：产品识别与主要行动是否成立；首屏构图、文字和媒体比例是否保留；模块顺序与疏密是否支持阅读；字体层次、图片裁切和组件状态是否一致；手机是否完成同一任务。媒体承担产品说明时，不能因图片缺失悄悄换成装饰框或文字墙。

有差异时分类：

- **实现偏差**：方案明确要求而当前未实现，写出具体关系与影响，交给建站修复。
- **合理适配**：真实内容、设备或素材使实现变化，但保留任务效果；说明依据，方案相应修订。
- **设计问题**：实际呈现忠实于方案却仍不能识别、阅读或选择，退回策划，而非反复调CSS。
- **偏好/建议**：没有明确违背需求且任务可完成，说明可能收益，不冒充阻断缺陷。
- **未知**：目标画面/当前状态未取得或版本不明，保留未验证。

同尺寸、同状态并排看能发现差别，但像素相似不等于质量，差异也不自动是缺陷。截图必须实际查看，不能把截图文件存在写成已目视。动画截图只证明该时刻；真实行为需要操作与连续状态证据。

避免“更高级、再精致一点”的任务。指出主次竞争、阅读密度、对齐断裂、裁切丢主体或操作位置不稳等具体关系，并说明修复后用户应看到什么。不为每次验收生成新设计方向；保留已确认的独特表现，不统一改成淡色、卡片或少动效。
