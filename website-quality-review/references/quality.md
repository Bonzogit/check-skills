# 内容与视觉判断

检查的是“本次设计有没有解决本次问题”，不是是否符合检查者喜欢的风格。大胆配色、密集信息或克制动效都可能成立，要结合内容、对象与原方案判断。

| 判断面 | 实际观察与操作 | 应报告的具体问题 |
|---|---|---|
| 业务识别 | 从入口看标题、主体图片、关键说明与主要行动是否表达同一件事 | 产品对象不明；图片与业务无关；主要按钮结果与文案不符 |
| 决策信息 | 沿主要路径寻找影响选择的差异、条件、规格、范围、证据与限制 | 缺少必要参数；对比维度不一致；服务边界不明；虚构事实或承诺 |
| 信息顺序 | 按阅读顺序判断每块是否回答上一阶段的问题；跳过装饰看路径是否成立 | 还没解释产品就索要联系方式；关键信息深埋；重复模块阻断阅读 |
| 视觉层级 | 观察首要信息、正文与行动能否区分；同级内容是否保持一致 | 所有标题同样抢眼；关键操作淹没；弱文字不可读；卡片权重与内容价值失配 |
| 排版与节奏 | 用真实长短标题、正文、参数与不同语言查看行长、断行、对齐和空间 | 标题孤字或压住图片；阅读行过长；单位错位；段落过密；空白与内容关系失衡 |
| 图片表达 | 查看主体、细节、比例、裁切、清晰度、背景和多图一致性 | 关键结构被切掉；概念图误作实物；同款角度冒作不同型号；装饰图挤掉选型信息 |
| 组件适用性 | 询问该组件是否帮助比较、理解或操作，再实际使用 | 轮播隐藏需要并排比较的信息；无意义标签页；筛选没有足够内容；装饰箭头像链接却不能点 |
| 行动与状态 | 实际走主路径，检查选项、反馈、最终结果与重返页面 | 上下文丢失；成功提示无保存凭据；失败清空输入；按钮在动画中移走；菜单关闭丢阅读位置 |
| 响应与可访问 | 在相关窄屏、触摸和键盘状态查看相同任务是否成立 | 手机仍依赖悬停；内容横溢；触摸滑动被截断；焦点丢失；禁用状态不明确 |
| 动效 | 观察起始/中间/终止、反向、重复、减少动态及暂停恢复 | 动效遮挡内容或阻碍操作；降低动态后内容消失；末尾无法释放滚动；图片慢导致空白 |

对参考只核对方案实际采用的部分，不要求复制无关商业内容、品牌标识或其他网站技术。设计参数偏离但仍合理时说明理由；没有效果影响的微小数值差异不自动判作缺陷。

## 按网站任务加查

- 产品选择：同一维度可比较、具体型号/选项与详情及后续请求一致，真实限制可找到。
- 服务获客：交付内容、适用条件和合作下一步清楚，表单不会过早索取无关资料。
- 交易预约：价格与条件不歧义、选项可确认、错误可恢复；未配置的真实能力明确区分，不把演示当商业完成。
- 内容品牌：内容组织与阅读顺序有意义，媒体加载和长文不会破坏阅读，下一篇或返回路径明确。
- 工具应用：输入要求清楚、结果可信可用、加载与失败有反馈，刷新/返回后的状态符合产品承诺。

只选择当前存在的任务，不为了跑全清单增加功能。完整网站按交付要求覆盖页面和设备，局部更改按影响选择；记录模拟器与实体环境区别。
