# 根据实际改动选择检查

| 范围 | 实际检查 | 不据此扩大 |
|---|---|---|
| 字体/间距/颜色 | 当前组件实际 DOM、computed style、长短文本、相关视口及对比度 | 不重跑邮件与数据库测试 |
| 图片/画廊 | 主体裁切、清晰比例、外框、稳定占位、失败/慢加载、触摸和键盘 | 不让隐藏大图争抢首屏 |
| 导航/菜单 | 打开关闭、焦点、链接、滚动锁、返回阅读位置、页眉变化后的定位 | 不只看菜单打开截图 |
| 滚动/动效 | 起始/中间/终止、正反向、点击定位、末尾释放、开关/减少动态、回放、后台与离屏恢复 | 加载库或 DOM 存在不算画面通过 |
| 表单/询盘 | 产品上下文、校验、提交中、保存编号、附件、失败重试、幂等；用隔离数据 | 不给真实客户发测试，不改原业务收件人 |
| 后台/内容 | 改标题/图/排序/发布后的前台同步；仅本次新增或受影响字段 | 不以初始化内容覆盖线上编辑 |
| 翻译 | 首屏已有译文、缺失时原文可读、异步更新/失败重试、长文本和适用 RTL | 不把任务 ready 当语义通过 |
| 部署/升级 | 原项目更新、当前公网版本/核心路径、工作台记录，按变更验证数据保留 | 构建或健康接口通过不算部署完成 |

完整网站覆盖电脑、平板、手机；手机 Chromium/WebKit 按用户要求与相关风险检查，报告模拟或实体。横向、窄屏、焦点和减少动态覆盖受影响项。不要给所有模块重复加相同显现或浮动，也不为验收减少用户明确保留的动效。

首次新项目保留一次基线。版本改变后相关检查需新证据；故障修复采用可复现用户行为，不改测试迎合现有缺陷。短小低风险修改只需实际观察与相关操作，无须新增镜像实现的测试。
